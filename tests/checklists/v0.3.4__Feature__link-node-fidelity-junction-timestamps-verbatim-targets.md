# Human Test Checklist: v0.3.4 -- Link-node fidelity (junction timestamps, verbatim targets, raw junctions, exact-ns times)

**Target version:** v0.3.4
**Ships with commit:** TBD (pre-commit checklist)
**Companion automated tests:** `tests/test_link_fidelity_v034.py` (6) + `tests/test_symlink_timestamps_v031.py` (2, regression-guarded). Full suite at authoring: 440 passed / 11 skipped.

## What this is

v0.3.4 fixes four link-node fidelity defects surfaced by the linkmirror engine work (mirroring all NTFS links off a failing drive) and adds two primitives (`create_junction_raw`, exact-ns link timestamps). This checklist verifies the behavior on a REAL NTFS filesystem in a real console -- reparse-point semantics, codepage rendering of errors, and the Win32 edge cases mocks can't reach. Everything runs unelevated in a scratch directory.

1. Windows 10/11, NTFS volume, Python 3.12+ with this repo installed editable (`pip show dazzle-filekit` -> Editable). Developer Mode ON or symlink-capable account.

## High-Value Verification (~5 minutes)

### HV.1 -- Junction timestamps land on the junction, not its target

Validates: the v0.3.4 headline fix (the v0.3.1 bug class, extended to junctions).

- [ ] **Steps** (PowerShell):
  ```powershell
  New-Item -ItemType Directory -Force $env:TEMP\fk034\tgt | Out-Null
  python -c "from dazzle_filekit.links import create_junction_raw; import os; e=os.environ['TEMP']; assert create_junction_raw(e+r'\fk034\tgt', e+r'\fk034\junc')"
  python -c "import os; from dazzle_filekit import apply_file_metadata; e=os.environ['TEMP']; t0=os.lstat(e+r'\fk034\tgt').st_mtime; ok=apply_file_metadata(e+r'\fk034\junc', {'timestamps': {'created': 1577836800.0, 'modified': 1577836800.0, 'accessed': 1577836800.0}}); print('applied:', ok); print('junction mtime is 2020:', abs(os.lstat(e+r'\fk034\junc').st_mtime-1577836800)<2); print('target untouched:', abs(os.lstat(e+r'\fk034\tgt').st_mtime-t0)<2)"
  ```
- [ ] **Expected:** `applied: True`, `junction mtime is 2020: True`, `target untouched: True`.
- [ ] **Why this matters:** before the fix this silently corrupted the TARGET directory's timestamps on every junction metadata restore.

### HV.2 -- create_junction_raw works with a NONEXISTENT target

Validates: broken junctions can be recreated (New-Item refuses them).

- [ ] **Steps** (PowerShell):
  ```powershell
  python -c "from dazzle_filekit.links import create_junction_raw; import os; e=os.environ['TEMP']; assert create_junction_raw(e+r'\fk034\no_such_dir', e+r'\fk034\junc_broken'); print(os.readlink(e+r'\fk034\junc_broken'))"
  ```
- [ ] **Expected:** prints `\\?\<TEMP>\fk034\no_such_dir`; `dir %TEMP%\fk034` shows `junc_broken` as `<JUNCTION>`.
- [ ] **Why this matters:** intentionally-broken junctions on a mirrored source must round-trip; the PowerShell path cannot create them at all.

### HV.3 -- Verbatim relative target survives creation byte-for-byte

- [ ] **Steps** (any shell):
  ```
  python -c "from dazzle_filekit.operations import create_symlink; import os; e=os.environ.get('TEMP','/tmp'); p=e+os.sep+'fk034'; os.makedirs(p, exist_ok=True); raw=r'sub\.\odd.txt' if os.name=='nt' else 'sub/./odd.txt'; assert create_symlink(raw, p+os.sep+'v_link', target_is_directory=False); print(repr(os.readlink(p+os.sep+'v_link')))"
  ```
- [ ] **Expected:** prints exactly the raw string (`'sub\\.\\odd.txt'` on Windows) -- no `.` segment collapsed, no separator flipped.
- [ ] **Why this matters:** Path() laundering was rewriting stored target bytes; readlink equality is the mirror's fidelity gate.

### HV.4 -- Exact-ns link timestamps round-trip to the tick

- [ ] **Steps** (PowerShell):
  ```powershell
  python -c "import os; from dazzle_filekit import apply_file_metadata; e=os.environ['TEMP']; p=e+r'\fk034'; os.path.lexists(p+r'\ns_link') or os.symlink('missing', p+r'\ns_link'); ns=1609459200123456700; ok=apply_file_metadata(p+r'\ns_link', {'timestamps': {'created_ns': ns, 'modified_ns': ns, 'accessed_ns': ns}}); st=os.lstat(p+r'\ns_link'); print('applied:', ok); print('mtime exact:', st.st_mtime_ns==ns); print('birth exact:', st.st_birthtime_ns==ns)"
  ```
- [ ] **Expected:** `applied: True`, `mtime exact: True`, `birth exact: True` -- equality at the nanosecond, not "close".
- [ ] **Why this matters:** the float path loses ~1-56us; verify passes downstream depend on tick-exact restore.

### HV.5 -- Broken DIRECTORY symlink honors explicit kind

- [ ] **Steps** (PowerShell):
  ```powershell
  python -c "from dazzle_filekit.operations import create_symlink; import os; e=os.environ['TEMP']; p=e+r'\fk034'; assert create_symlink(r'no\such\dir', p+r'\bd_link', target_is_directory=True); print('DIR bit:', bool(os.lstat(p+r'\bd_link').st_file_attributes & 0x10))"
  ```
- [ ] **Expected:** `DIR bit: True`.

### 1.2 create_junction (PowerShell path) still works for EXISTING targets

### 1.3 Relative-target kind probed against the LINK's parent, not CWD

- [ ] **Steps** (PowerShell, note the cd):

  ```powershell
  New-Item -ItemType Directory -Force $env:TEMP\fk034\sub\real_dir | Out-Null
  cd $env:TEMP\fk034
  python -c "from dazzle_filekit.operations import create_symlink; import os; e=os.environ['TEMP']; assert create_symlink('real_dir', e+r'\fk034\sub\dlink'); print('DIR bit:', bool(os.lstat(e+r'\fk034\sub\dlink').st_file_attributes & 0x10))"
  ```
- [ ] **Expected:** `DIR bit: True` even though CWD (`fk034`) has no `real_dir`.

### 1.4 Error rendering in cmd.exe

- [ ] **Steps** (cmd.exe): attempt `create_junction_raw` onto an already-existing path without force; watch the logged warning.
- [ ] **Expected:** ASCII-only, single-line, states the path exists. No traceback, returns False.
